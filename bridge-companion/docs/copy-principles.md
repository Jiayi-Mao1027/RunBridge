# Bridge Companion Copy Principles

## Core Rule

```text
准确、克制、用户可读。
视觉可以二创，事实不能二创。
```

Bridge Companion 的主文案必须像运行日志一样诚实。界面可以像任务板，但信息不能变成奇幻叙事。

## 1. 主信息不改名

不要在事实主卡里写：

```text
符文匠正在锻造代码
桥门深处传来回响
异兆猎人准备出动
```

应该写：

```text
实现代理正在处理任务
桥接窗口已开启
异常分析阶段尚未触发
```

可以主题化的是背景、图标、像素小人、任务板布局、卷宗卡片、地图路线、火光动效。不能主题化的是运行事实本身。

## 2. 解释事实，不文学化事实

如果当前状态是 team_waiting，不要写：

```text
远端工坊仍有敲击声，符文匠正在黑暗中锻造骨架。
```

应该写：

```text
任务已下发，当前处于等待队员返回结果的阶段。暂时没有新的结构化回报。
```

可以在弱装饰区域写：

```text
同伴札记：后台仍在处理，前台暂无新消息。
```

## 3. 不知道的地方必须明说

如果 runtime 只知道 message_dispatch_completed 和 team_waiting，那么 UI 不能写：

```text
正在修改 trainer.py
正在写 DPO loss
正在集成 reward model
```

正确写法是：

```text
任务说明已下发，执行团队正在后台处理。当前 runtime 尚未收到新的文件变更、报告或 artifact，因此无法确认具体正在修改哪些文件。
```

## 4. TeamIdle 不是完成

TeamIdle / team_waiting / waiting 只能表示 runtime 正在等待，不代表任务完成，不代表即将完成，也不代表一定卡死。

推荐写法：

```text
当前处于等待执行结果阶段。runtime 暂未收到新的结构化报告、artifact 或完成信号。
```

## 5. 下一步来自状态机

下一步不能写成概率判断或乐观预测。

不要写：

```text
下一步应该会完成核心模块。
```

应该写：

```text
按当前 lifecycle，下一步可能是收到 artifacts_ready、completion_contract_satisfied、completion_contract_rejected，或失败/超时相关事件。
```

用户版可以写：

```text
下一步通常会是：收到阶段性报告、进入完成条件检查，或在超时/失败时返回异常信息。
```

## 6. 三层文案结构

事实层示例：

```text
当前阶段：l4_implement / 实现阶段
当前状态：桥接窗口已开启，任务已下发，正在等待队员回报
最新事件：team_idle_waiting
最后更新时间：14:02:20
当前结果：尚未收到 completion report
```

解释层示例：

```text
这表示任务已经进入 bridge window 内部执行阶段。Bridge leader 已将任务说明发送给执行团队，目前 runtime 正在等待后续回报。
```

氛围层示例：

```text
同伴札记：小队还没带回新卷宗。此处只显示已被 runtime 记录的事实，不猜测未返回的细节。
```

## 7. 状态文案模板

语义已冻结：

```text
当前状态：任务语义已冻结
主控已锁定本轮任务目标、约束和执行范围。下一步将根据当前阶段构建桥接任务包。
```

桥接任务包已生成：

```text
当前状态：桥接任务包已生成
runtime 已根据当前快照生成本轮 BridgePacket。该任务包包含目标阶段、队员配置、可用工具、完成条件和报告要求。
```

桥接窗口已开启：

```text
当前状态：桥接窗口已开启
Bridge leader 已接收任务包，并为本轮执行创建独立的桥接窗口。
```

执行团队已创建：

```text
当前状态：执行团队已创建
本轮任务所需的执行团队已经创建完成，后续消息将发送给对应队员。
```

任务说明已下发：

```text
当前状态：任务说明已下发
执行团队已收到任务目标、完成条件和报告要求。runtime 正在等待后续执行结果。
```

等待执行结果：

```text
当前状态：等待执行结果
当前处于 bridge window 内部等待阶段。runtime 暂未收到新的结构化报告、artifact 或完成信号。
```

完成条件未满足：

```text
当前状态：完成条件未满足
队员已有返回，但 runtime 检查发现结果尚未满足本轮 completion contract。
```

部分结果返回：

```text
当前状态：部分结果返回
本轮 bridge window 返回了部分结果。任务没有完整失败，但仍有未满足或未确认的项目。
```

执行失败：

```text
当前状态：执行失败
本轮 bridge window 已返回失败结果。失败阶段、错误信息和可用证据已记录在 runtime 中。
```

任务完成：

```text
当前状态：任务完成
本轮 bridge window 已返回成功结果，并满足当前 completion contract。
```
